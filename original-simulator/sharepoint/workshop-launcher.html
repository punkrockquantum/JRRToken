Prompt to Compute to Tokens

An interactive simulator of the AI inference stack: watch a prompt travel through a frontier model token by token, then tune the infrastructure — silicon, cooling, network, datacenter — and see how the tokenomics change.

Open the simulator (hosted here) works for everyone, runs entirely in your browser Open the live dev version (presenter’s machine) only works on the machine running the local dev server
Nothing leaves your browser: the simulator has no backend and makes no network calls. Figures are from public vendor datasheets; proprietary model sizes and prices are labelled estimates.
