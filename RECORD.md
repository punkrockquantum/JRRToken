# The record for this work lives elsewhere

This repository is the **pipeline**: `cryptanalysis-pipeline/` (the instrument,
its four pre-registrations and its 44-record evidence chain) and
`algebraic-probe/` (the retired predecessor). It holds no written record of
what the work established, and it should not hold one, because two copies of a
record drift and only one of them gets corrected.

**Canonical record:** `docs/record.md` in `punkrockquantum/algo-tools`.

It carries the four pre-registrations and their statuses, the benchmarks with
what each one does not show, the defect log, what is untested, and a dated
corrections section listing every claim withdrawn or restated since 26 Sep
2026.

## This repository is the cited source

`algo-tools` copies this repository's chain and three of its pre-registrations
byte-for-byte into `casestudy/`, with their sha256 digests and this commit
pinned in `casestudy/manifest.json`:

| | |
| --- | --- |
| Commit cited | `2a6e4fd4494f4a117c3fb1c61021929c46678578` (26 Sep 2026) |
| Branch | `claude/algebraic-probe-skeleton-2uaojo` |
| Directory | `cryptanalysis-pipeline` |
| Files copied | `runs/log.jsonl`, `prereg/PREREG-002…md`, `prereg/PREREG-003…md`, `prereg/PREREG-004…md` |

That commit must stay reachable. Commits after it do not break the citation —
the manifest pins a hash, not a branch tip — but rewriting history across it
would.

## One thing this pointer does not solve

`punkrockquantum/algo-tools` is not public. For anyone outside the project the
link above currently resolves to nothing, so this repository is a citable
source whose record is not citable. That is unresolved, and it is recorded here
rather than papered over by keeping a second copy that would drift.
